# かんたんPDF分割

名古屋テクノロジーが無料配布するWindows用PDF分割アプリ。Versionは `Directory.Build.props` を唯一の情報源としてビルド・配布物に反映します。C# / WPF / .NET 10 LTS / PDFsharp 6.2.4 / NSIS 3.13。

## 使い方

1. PDFを画面にドラッグするかクリックして選びます。
2. 「1ページずつ」または「指定ページの後」を選びます。指定位置は `5,12` のように半角数字をカンマで区切ります。
3. 出力ファイル名・ファイル数・ページ範囲を確認し、保存先を選びます。
4. 変更内容の確認欄が表示された場合は、影響を読んでチェックを入れます。
5. 「PDFを分割する」を押します。完了後「保存先を開く」で結果を確認できます。

元PDFは変更しません。画像化せずページの内容・サイズ・回転・各ページボックスをコピーします。連番は最低3桁、ページ数に応じて増やします。重複指定・範囲外・空要素・不正文字はエラー。最終ページ指定は空区間を作りません。同名出力は上書きせず停止。出力先で一時生成・再読込後に公開し、失敗時は今回の出力を削除します。OSや他アプリに削除を拒否された場合は残留ファイルを表示します。電源断・プロセス強制終了の場合は `.kantan-pdf-*` 一時フォルダーや一部の出力が残る可能性があります。

## 対応範囲

Windows 10 / 11 **x64**。Windows 10は22H2以降を対象。Self-contained配布のため.NETの事前インストールもインターネット接続も不要。Windows ARM64 / x86は本リリースの対象外。長いパスに対応したマニフェストを同梱していますが、Windows側の設定とファイルシステムの制限は引き続き適用されます。セキュリティ設定は変更しません。

1.0.1では通常のWeb・メールリンク、ページ内リンク、しおり、移動先の名前、一般的な注釈、透明度設定、ページのサイズ倍率に対応します。リンクやタグの存在だけで拒否しません。同じ出力PDFに含まれるページへのリンクを付け直し、しおりと移動先の名前も対象ページのものを引き継ぎます。出力外へのページ内リンクは移動操作を無効にして見た目を残します。読み上げ用の構造情報は再構築しないため、読み上げ順序やアクセシビリティが変わる可能性があります。これらの影響は分割前に表示し、確認チェックが必要です。起動時の移動先・表示設定も通知して省略します。

暗号化（開くパスワードが空でも利用制限があれば拒否）、電子署名、入力フォーム、添付、スクリプト・自動実行、外部ファイル操作、動画・特殊な注釈、レイヤー、対応していないページ設定は、具体的な理由を表示して拒否します。読み込みエラーになったPDFの名前を表示し、通常の未選択状態と区別します。パーサーで圧縮オブジェクトと名前のエスケープを解釈して検査します。**電子署名の有効性は分割後に維持されません。** 文書タイトル・著者・件名・キーワード・言語・色プロファイルは保持し、作成者は本アプリ名になります。XMLメタデータとPDF/A・PDF/UA準拠の維持は保証しません。

実際の問題PDFは提供されていないため、そのPDFを直せたことや生成ソフトは未確認です。Office/Googleドキュメント相当の合成PDFで回帰を検証しています。詳しい保持方針とqpdf比較は [PDF互換性メモ](docs/pdf-compatibility-1.0.1.md) に記録しています。

処理はバックグラウンドで行います。二重実行と処理中の入力変更・終了を防止。PDFsharpは文書をメモリに読み込むため、大容量PDFは空きメモリに依存し、解析中・1ファイルの保存中の中断はできません。UIは応答します。

## インストール・更新

`KantanPdfSplitter-Setup-1.0.1.exe` を実行。管理者権限不要、`%LOCALAPPDATA%\Programs\KantanPdfSplitter` にインストールし、デスクトップ・スタートメニューと「インストールされているアプリ」に登録します。同一バージョンの再実行で修復、上位版で更新可能。下位版への戻しは警告して拒否。実行中はインストール・アンインストールを拒否します。

アンインストールは**インストーラーが所有する個別ファイルだけ**を削除します。元PDF・生成PDFやユーザーが追加したファイルを削除しません。更新時も古い配布ファイルを記録した管理リストで処理します。署名は現時点で行いません。Windowsの警告を回避するためのセキュリティ変更はしないでください。

## 開発・検証

PowerShell 7、.NET SDK（`global.json`）、Windowsが必要です。

```powershell
./scripts/Build-Assets.ps1
dotnet restore KantanPdfSplitter.slnx --locked-mode
dotnet build KantanPdfSplitter.slnx -c Release --no-restore
dotnet test KantanPdfSplitter.slnx -c Release --no-build
./scripts/Build-Installer.ps1
./scripts/Test-InstallerSmoke.ps1
```

通常CIはWindows 2025でrestore / build / tests / self-contained publish / NSIS / installer smokeを実施し、大きな配布物は保存しません。手動実行またはReleaseでSetup・ZIP・SHA-256を7日保存します。将来の署名は `Build-Installer.ps1` の `-SignPublishedFilesScript` と `-SignToolCommand` を両方指定します。前者は `-PublishDirectory` を受け取り、publish後のPEファイルを署名する外部PowerShellスクリプトです。全PEの署名検証後にNSISへ渡し、後者でuninstallerとSetupを署名します。署名証明書や認証情報はリポジトリに保存しません。

実機のアプリケーション制御で起動できないことが確認された環境では、installer lifecycleだけを `Test-InstallerSmoke.ps1 -SkipAppLaunch` で検証できます。起動項目は明示的にUNVERIFIEDと記録します。通常CIではこのオプションを使わず、実際のMain Window起動も必須です。
